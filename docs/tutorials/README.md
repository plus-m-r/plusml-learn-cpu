## 💡 学习建议

### 实验流程

1. **阅读教程**: 理解实验目标和原理
2. **编写代码**: 按照教程实现设计
3. **运行测试**: 验证功能正确性
4. **查看波形**: 分析时序行为
5. **总结反思**: 记录学到的知识

### 调试方法

- 使用 `println` 打印中间值
- 生成 VCD 波形文件
- 使用断言检查预期行为
- 逐步增加复杂度
