## 📚 推荐书籍

### 数字设计基础
1. **《Digital Design and Computer Architecture》** - David Money Harris & Sarah L. Harris
   - 涵盖数字设计和计算机架构
   - 有 RISC-V 版本
   - 适合初学者

2. **《Computer Organization and Design RISC-V Edition》** - David A. Patterson & John L. Hennessy
   - 经典的计算机组织与设计
   - RISC-V 指令集详解
   - 适合深入学习

3. **《See MIPS Run》** - Dominic Sweetman
   - MIPS 架构深入讲解
   - 有助于理解 RISC 架构

### Chisel 相关
4. **《Digital Design with Chisel》** - Fabian Schupbach
   - 专门针对 Chisel 的教材
   - 理论与实践结合

5. **《Scala for the Impatient》** - Cay S. Horstmann
   - Scala 编程语言快速入门
   - Chisel 基于 Scala,了解 Scala 有帮助

## 💡 学习路径建议

### 初级阶段 (1-2个月)
1. 学习 Scala 基础语法
2. 完成 Chisel Bootcamp
3. 实现基础组合逻辑电路
4. 掌握时序逻辑设计

### 中级阶段 (2-4个月)
1. 学习 RISC-V 指令集
2. 实现 ALU 和寄存器文件
3. 构建单周期 CPU
4. 学习测试和验证方法

### 高级阶段 (4-6个月)
1. 实现流水线 CPU
2. 添加缓存系统
3. 性能优化
4. 在 FPGA 上运行
