# Chisel 设计效果查看指南

## 📊 查看效果的几种方式

### 1️⃣ **查看生成的 SystemVerilog 代码**
```bash
cat generated/SimpleAdder.sv
```
这是 Chisel 编译后生成的硬件描述代码。

---

### 2️⃣ **运行测试并查看控制台输出**
```bash
# 运行所有测试
sbt test

# 运行特定测试
sbt "testOnly WaveformTester"
```

你会看到类似这样的输出:
```
==================================================
SimpleAdder 测试结果:
==================================================
✓ Test 1:   0 +   0 =   0 (期望:   0)
✓ Test 2:   1 +   2 =   3 (期望:   3)
✓ Test 3:   5 +  10 =  15 (期望:  15)
...
```

---

### 3️⃣ **查看波形文件 (VCD)**

测试会生成 VCD (Value Change Dump) 波形文件,位置在:
```
test_run_dir/SimpleAdder_with_Waveform_should_generate_waveform_for_debugging/SimpleAdder.vcd
```

#### 安装 GTKWave (波形查看器):
```bash
sudo apt update
sudo apt install gtkwave
```

#### 打开波形文件:
```bash
gtkwave test_run_dir/*/SimpleAdder.vcd
```

在 GTKWave 中:
- 左侧选择信号 (io_a, io_b, io_sum, clock)
- 拖拽到右侧波形区域
- 可以看到信号随时间变化的波形图

---

### 4️⃣ **使用 Verilator 进行仿真**

如果你想用 Verilator 仿真生成的 SystemVerilog 代码:

```bash
# 安装 Verilator (已安装)
verilator --version

# 编译 SystemVerilog 为 C++ 仿真模型
verilator --cc generated/SimpleAdder.sv --exe --top-module SimpleAdder

# 运行仿真
make -C obj_dir -f VSimpleAdder.mk
./obj_dir/VSimpleAdder
```

---

### 5️⃣ **创建更复杂的可视化**

你可以修改 `src/main/scala/SimpleAdder.scala` 来创建更复杂的电路,例如:

- **ALU (算术逻辑单元)**
- **寄存器文件**
- **状态机**
- **完整的 CPU 流水线**

然后运行 `sbt run` 生成对应的硬件描述。

## 🔧 常见问题

**Q: 如何修改设计?**
A: 编辑 `src/main/scala/SimpleAdder.scala`,然后运行 `sbt run` 重新生成

**Q: 如何添加新测试?**
A: 在 `src/test/scala/` 下创建新的测试文件

**Q: 波形文件在哪里?**
A: `test_run_dir/` 目录下,每次测试都会生成新的子目录

**Q: 如何清理项目?**
A: 运行 `sbt clean`
